# ModicumFM: MIDI 2.0 / MPE / CLAP port

Written 2026-10-14 to start the port of PlainOldSynth's 2026-10-09..12 work; kept up to date as it
goes. Status: **everything but L (Linux CI) done.**

The same work was done first in three sibling repos; port from them rather than re-deriving:

- **IFSynth** (`~/Dev-Audio/IFSynth`, branch **`master`**): the most recent port, from the same
  DPF-generated starting point; its `docs/MIDI2-PORT.md` is the model for this file.
- **StruckSynth** (`~/Dev-Audio/StruckSynth`, branch `main`): also has no VCA (its bank's decay is the
  envelope) and a fixed Expression panel instead of routing dropdowns, so it is the model for item 3.
- **PlainOldSynth** (`~/Dev-Audio/PlainOldSynth`, branch `main`): where most of it began; its README
  "MIDI 2.0" section is the reference.

All of them vendor the same PolygraphModular engine (`src/Common`, `src/Module`, `src/Voice`).
ModicumFM's `pm_midi.*` and `VoiceStateManager.cpp` are identical to POS's before the port
(`8a3f6be`), so engine commits port nearly file for file: `git show <commit> -- src > x.patch`, then
`git apply --reject x.patch`, and place the rejected hunks by hand.

## ModicumFM as it was (2026-10-14)

- **The CLAP is generated by DPF** (`dpf_add_plugin`), which hands the plugin MIDI 1.0 bytes only:
  no MIDI 2.0, no note ids, no note expressions. Step 0 replaces it.
- **The voice** (`VoiceManager::buildDefaultPatch`): (PitchConverter + PitchBendConverter) →
  Combine 2 (Add) → FM6Op pitch → LPF (filter ADSR on cutoff mod 1, ChannelPressure on mod 2) →
  Chorus (SharedLFO) → Final. **No VCA**: the carriers' envelopes are the amp, and a voice frees once
  Final falls silent. FM6Op reads gate and velocity from the MIDI note-on itself (`fmVelocityLevel`,
  Touch).
- **No modulation routing dropdowns**: pressure is hard-wired to the filter cutoff.
- **Parameters** are appended, never inserted (the host-facing id is the index).

## Planned after the port: mono glide

The author wants glide for mono (2026-10-14). UI-visible (a new param and control), so agree the
placement and range first. Wiring, as IFSynth: PitchConverter → **Slew** → Combine 2 input 1, with
the PitchBendConverter staying on input 2, so the bend (and Pitch 7.25, applied in the bend
converter) joins after the glide and is never smeared by it. Mono only: in poly force the slew
near-instant, or each new voice slides up from its rest pitch. Bring back IFSynth's host test
"a bend bypasses the glide" (`ifs_clap_host_test.cpp`).

## Decisions (2026-10-14)

1. VST3 / AUv2 through clap-wrapper: later, not in this port.
2. MPE switch: Global, with the Global dropdowns restacked into two rows (step 7).
3. Pressure and Timbre: a fixed Expression panel on the Voice tab under Character, with Press>Level
   added (step 3, agreed 2026-10-14).
4. Velocity loudness dropdown: skipped (step 8).

## Working with the author

- Commit to `main` directly, no pull requests; ask before pushing.
- Ask before anything UI-visible: new parameters, panel controls, dropdown entries.
- Before each commit: `ctest --test-dir build` and `clap-validator validate` on the built `.clap`.
- After a rebuild, **quit and restart the host**: a running host keeps the binary it first loaded.
- Synths accept MPE as a compatibility input and never send it.
