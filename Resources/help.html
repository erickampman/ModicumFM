TwinFM

A dual 4-operator FM synthesizer — reference for every section.

Each voice runs two independent FM engines, A and B, mixed in stereo, then through a resonant low-pass filter, an amplifier envelope and a chorus:

FM A + FM B → Mixer → Low-Pass Filter → Amp → Chorus → Master

Pitch bend moves both engines; channel pressure (aftertouch) opens the filter.

FM Engine A / B

The A | B tabs switch which engine the panel shows; both always play. Each engine has four sine-based operators. An algorithm decides which operators modulate which: a carrier is heard, a modulator bends a carrier's phase to add harmonics.

Algorithm
Operator routing. 4>3>2>1 is one stack (4 modulates 3, 3 modulates 2, 2 modulates the carrier 1); (2,3,4)>1 is three modulators on one carrier; Parallel is four carriers (additive). Only carriers are heard directly.
Feedback
Operator 4 modulates itself — from a brighter sine toward a buzzy, saw-like tone.
Pitch / Fine
Transpose the whole engine in semitones / cents. Detuning engine B a few cents against A (the default) thickens the sound.
Detune
Stereo detune within the engine (left and right drift apart).
Oversample
Off / 2x / 4x. Reduces aliasing on bright, high-index patches at extra CPU cost.

Each operator row:

Wave
Sine, or a small harmonic stack (1+2, 1+3, 1+3+5, 1-4) for richer modulators and carriers.
Ratio / Fine
Operator frequency as a multiple of the note. Whole-number ratios give harmonic tones; in-between ratios give bells and metallic sounds.
Level
For a carrier, its loudness. For a modulator, the modulation index — how many harmonics it adds.
Delay / Attack / Decay / Sustain / Release
The operator's own envelope. On a modulator it shapes the timbre over time (e.g. a bright attack that mellows).

Mixer

A / B Level
How much of each engine goes to the filter.
A / B Pan
Stereo position of each engine.

Low-Pass Filter + Filter Envelope

Cutoff
Filter frequency. Everything above it is rolled off (24 dB/octave).
Resonance
Emphasis at the cutoff.
Env Amount
How far (in octaves) the Filter Envelope moves the cutoff; negative values sweep it down.
Pressure
How far (in octaves) channel pressure / aftertouch moves the cutoff.
Attack / Decay / Sustain / Release
The filter envelope, triggered by each note.

Amp Envelope

The overall loudness contour of each note. A voice is freed once its release has faded.

Chorus

Mix
Dry / wet balance.
Rate
Speed of the chorus sweep. One LFO drives every voice, so all notes sweep together; left and right run 90° apart for width.
Depth
How far the delay sweeps (milliseconds).
Delay
Base delay time — shorter is tighter, longer is lusher.
Feedback
Feeds the chorus back into itself for a more resonant, flanger-like colour.

Global

Voices
Poly (10 voices) or Mono (legato: a note played while another is held changes pitch without re-attacking the envelopes).
Bend Range
Pitch-bend range, up to 4 semitones each way. Off ignores pitch bend.
Master
Output level.
